# FixMate

FixMate is a local services marketplace prototype that connects customers with service providers.

## Branch 0.2

This branch contains the static HTML prototype. It includes page designs for:

- Landing page
- Login page
- User dashboard
- Provider directory
- Provider profile
- Provider dashboard
- Booking checkout
- Admin dashboard

## Run the Prototype

No build tools or server are required. Open `Landing_page.html` in a browser, then use the links in the page to explore the prototype.

For the most reliable browser behavior, serve the repository with any simple local static server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000/Landing_page.html>.

## Project Files

The page files are kept at the repository root. Design diagrams are included as `ER Diagram.png` and `Flowchart.png`.
